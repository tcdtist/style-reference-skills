# Style Reference Skills

Collection of DESIGN.md style references for AI agents to build consistent UI.

## Overview

This repository contains curated design system references (DESIGN.md files) from popular brands. AI agents can use these files to understand and replicate specific design styles when building user interfaces.

## Usage

### MCP Server

The MCP server provides tools to search and load style references:

- `search_style_references` - Search by brand, mood, color
- `get_style_reference` - Load full DESIGN.md file
- `list_style_references` - List all available brands

### Manual Usage

Copy the DESIGN.md file for a brand into your project root. AI agents will read it before generating UI.
